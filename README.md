# GOV-DYNAMICS

Governance documentation repository for Manus LEGO / LOOP Dynamics.

This repository stores architecture documentation, governance records, schemas, agent specifications, and verification evidence. It is **documentation-only**, not an executable monorepo. The directories mirror the intended modular TypeScript + Python application architecture.

See `registry/manifest.json`, `registry/directory-index.csv`, and `docs/architecture/architecture.md`.

Do not commit secrets, operational databases, or private records. No build, integration, deployment, or NIST compliance is claimed by this documentation.
