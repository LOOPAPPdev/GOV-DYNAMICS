# services

**Objetivo:** Serviços e responsabilidades de backend.

Este diretório contém documentação e referências para o correspondente módulo da arquitetura alvo. Não contém uma implementação executável.

**Adicionar documentos:** registar o identificador estável, caminho, fonte, versão e estado em `registry/master-index.csv`. Preservar aliases e links de origem; alterações semânticas exigem crosswalk e revisão.

**Gate:** conteúdo sensível não deve ser publicado neste repositório público. O estado de implementação, testes e conformidade só pode ser marcado verificado com evidências.
